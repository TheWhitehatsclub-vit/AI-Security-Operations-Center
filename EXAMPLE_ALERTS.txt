======================================================================
  FIELD REFERENCE
======================================================================

  Field                Type     Always present   Description
  ─────────────────────────────────────────────────────────────────────
  id                   string   yes              UUID v4
  timestamp            string   yes              ISO 8601 UTC
  rule_name            string   yes              Rule that fired
  category             string   yes              web|auth|malware|...
  severity             string   yes              LOW|MEDIUM|HIGH|CRITICAL
  confidence           float    yes              0.0 to 1.0
  confidence_boost     float    yes              Sum of all boosts
  confidence_factors   array    yes              [["baseline",0.05],...]
  ttp                  string   yes              MITRE ATT&CK ID
  kill_chain           string   yes              Recon|Exploit|Install|...
  source_ip            string   yes              Attacker IP
  matched_value        string   yes              What the pattern caught
  matched_pattern      string   yes              The regex/threshold rule
  description          string   yes              Human-readable summary
  incident_id          string   yes              "" if solo, "inc-..." if grouped
  geo                  obj      yes              {country, city, asn, isp}
  raw_log              obj      no               Original log (may be empty)
